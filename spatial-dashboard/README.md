# Geoxis — live 3D operations globe

Vanilla JS + Vite + Cesium. Positions come from `GET /api/assets` (Vercel function, same handler in `vite` dev).

```bash
npm install
npm run dev
```

Open http://localhost:5173 — globe, fleet, optional live aircraft. No API keys required.

Optional in settings: Google Map Tiles key, OpenAI key for the assistant.
